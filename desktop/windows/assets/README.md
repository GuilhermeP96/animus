# Marca Datano

`datano.svg` é o símbolo vetorial oficial da Datano, com a geometria original.
`datano.png` é sua renderização RGBA em 256 × 256 px, com tratamento ciano para
o fundo escuro do Animus. O PNG é incorporado ao executável; não há download de
imagens nem dependência de rede para desenhar os créditos.

Origem da marca: [Datano](https://datano.com.br/). Os direitos da marca permanecem
com seus titulares; veja também TRADEMARKS.md na raiz do projeto.
