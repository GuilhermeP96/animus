Generate a self-contained installer kit with the hub URL, HMAC secret and a node_id already baked in. Reusing a known ID makes the same ZIP an idempotent update/repair kit, with alias or hostname resolved from the peer registry. No source code — just the wrapper scripts. Works for shells and for GitHub Copilot in VS Code (read COPILOT.md inside the ZIP).

  1. Click Generate Installer ZIP above (~few KB; secret is embedded)
  2. Extract anywhere on the target machine
  3. Linux/macOS: ./install.sh   ·   Windows: double-click install.bat
  4. No prompts — the kit already knows hub URL, secret, and node id
🤖 No shell access? Open the extracted folder in VS Code and ask Copilot: "Follow COPILOT.md to install the Animus peer using values from peer.env."
⚠️ The secret is the only credential — anyone holding it can push memories to the hub. Treat it like a password. To rotate, change ANIMUS_SERVER_SECRET in .env, restart the container, and re-run the installer on each peer.
